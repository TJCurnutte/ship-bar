# ship-bar

A free review-loop skill for AI agents that build websites: 20 reviewer agents score every build from screenshots and checks, and nothing ships until the median hits **9.7/10** with no blockers.

- **Skill:** [`SKILL.md`](./SKILL.md) — drop it into your agent's skills or instructions.
- **Site:** https://ship-bar.neural-forge.io
- **White paper:** https://ship-bar.neural-forge.io/whitepaper
